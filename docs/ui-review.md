# UI 产品化审查

## 本次处理

| 问题 | 调整 |
| --- | --- |
| 比赛时品牌、口号、英文装饰和操作说明占用视野 | 品牌仅在开始、暂停及结算菜单中出现；操作说明默认折叠 |
| 名次、圈数和全程进度重复表达信息 | 删除全程进度条；保留名次、圈数和速度，手机隐藏次要计时 |
| 暂停按钮离手机常用操作区远且视觉过重 | 左上角 32px 按钮图形，保留 44px 触摸范围 |
| 暂停与结算复用宣传式文案 | 暂停显示“已暂停”与继续按钮；结算独立展示名次和用时 |
| 重力模式仍显示方向与油门按钮 | 重力模式突出左右两侧的刹车、氮气；回正保留右上角 |
| 弯道、路肩、圈数和碰撞提示会竞争空间 | 单一提示区域，路肩/碰撞优先于圈数，圈数优先于弯道 |
| 氮气不足时只有颜色变化 | 加入蓄能中、释放中、加速中的简短状态；说明中保留 25% 门槛 |
| 长说明与最小页面高度挤压横屏 | 菜单支持滚动，加入安全区间距和矮横屏布局 |
| 隐藏的驾驶控制可能进入键盘操作 | 菜单打开时设置驾驶区 inert，焦点限制在菜单，方向键不触发油门 |
| 加载错误混入比赛提示 | 场景加载信息放在菜单中；画面丢失独立显示重新加载入口 |
| 主标题链接误触会重载比赛 | 菜单品牌改为无跳转标识 |

## 验证与后续

已通过生产构建与 UI 控制器自动测试，覆盖开始、暂停、继续、结算、重玩、提示互斥、重力模式显示状态及菜单键盘隔离。

未进行浏览器截图审查或手机真机验证。下一步需确认 iOS/Android 横竖屏安全区、双手握持时按钮位置、大字体菜单滚动以及重力模式下回正操作的舒适度。测试不代表上述实机体验已经验证。
